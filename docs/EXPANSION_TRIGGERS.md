# Expansion Triggers

**Phase 4 — Controlled Beta → Expansion Gates**  
**Owner:** Lead Architect (Kalyan project)  
**Last Updated:** 2026-10-05

> These are the three quantitative gates that must be met before any feature expansion
> out of controlled beta. No feature work should begin until the relevant gate is cleared.
> All metrics must be measured over a 14-day rolling window unless otherwise noted.

---

## Gate 1 — WhatsApp Channel Activation

**Trigger:** Activate WhatsApp as a live reply channel (beyond staged/test mode).

**Condition (either):**
- WhatsApp WMCR (Weekly Message Count Rate) >= **100 messages/week** sustained for 2 consecutive weeks, **OR**
- Waitlist registrations >= **1,000 entries**

**Measurement:**
- WMCR: `backend/app/services/wmcr_analytics.py` → `compute_wmcr()` output
- Waitlist count: `SELECT COUNT(*) FROM waitlist_entries WHERE created_at >= NOW() - INTERVAL 7 DAYS`

**Blockers until gate clears:**
- `WHATSAPP_TOKEN` and `WHATSAPP_PHONE_NUMBER_ID` credentials must be provided
- `ENABLE_LIVE_SOCIAL_BROADCAST=true` must be set in production env

---

## Gate 2 — Paid Voice / Premium Tier Launch

**Trigger:** Launch a paid "Voice" conversion tier or premium subscription.

**Condition (both must hold simultaneously):**
- Voice feature conversion rate >= **2%** of active beta users
- Gross margin >= **40%** (revenue minus LLM cost)

**Measurement:**
- Conversion rate: `(users_subscribed_voice / total_active_users) * 100`
- Gross margin: `((revenue_inr - llm_cost_inr) / revenue_inr) * 100`
- LLM cost from: Razorpay revenue webhooks vs `COST_PER_1K_*_TOKENS_USD` × `INR_PER_USD`

**Blockers until gate clears:**
- `RAZORPAY_KEY_ID` and `RAZORPAY_KEY_SECRET` must be provided and live
- Payment webhook HMAC verified end-to-end in production

---

## Gate 3 — Creator Portal / Organic Situation Generation

**Trigger:** Open the creator portal for third-party situation/lore contributions.

**Condition:**
- >= **50 organic situations** generated by the beta cohort (not seeded by the team) with a quality rating >= 4/5

**Measurement:**
- Organic situations: `SELECT COUNT(*) FROM character_lore WHERE created_by != 'system' AND quality_rating >= 4`
- Quality rating: operator-reviewed approval queue (`/api/v1/approval/candidates`)

**Blockers until gate clears:**
- Approval queue processing time < 2h median (R6 alert must not be firing)
- Creator portal UI (not built yet — this gate is a prerequisite for building it)
